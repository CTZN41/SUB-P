# ShotMap AI 영상 시험 계획과 정답표

## 1. 문서 목적

AI 결과가 맞는지 판단하려면 사람이 먼저 영상의 정답을 기록해야 합니다. 이 문서는 개발용 샘플 영상과 직접 촬영 영상의 사용 범위, 정답 기록 방법과 정확도 계산 방식을 정합니다.

YouTube 영상은 링크 확인용입니다. 원본을 프로젝트나 발표 자료에 포함하기 전에는 제작자의 허락 또는 사용 가능한 라이선스를 확인합니다.

## 3. 직접 촬영 권장 조건

- 가로 화면
- MP4
- 최소 1080p
- 가능하면 60fps
- 카메라 고정
- 반코트 전체, 골대, 림과 주요 코트 선이 계속 보임
- 선수 발과 전신이 가능한 한 보임
- 촬영 중 확대·축소와 좌우 회전 없음
- 다른 사람이 나오면 촬영과 분석 동의를 얻음

## 4. 직접 촬영 영상에 넣을 장면

### 1분 영상

- 5~10개 정도의 슛
- 성공과 실패가 모두 포함
- 최소 두 곳 이상의 슛 위치
- 제자리 슛과 드리블 풀업 포함
- 가능하면 레이업 한 개 이상 포함

### 10분 영상

- 슛을 하지 않는 이동과 공 줍기 장면 포함
- 여러 코트 구역에서 슛
- 성공과 실패가 섞임
- 제자리, 풀업, 레이업과 가능한 다른 슛 종류 포함
- 영상 처음과 끝에 가까운 슛 포함
- 분석을 취소하고 다시 시도할 수 있는 충분한 길이

## 5. 정답표 작성 규칙

- 영상 시간은 가능하면 0.1초 단위로 기록합니다.
- 슛 준비 시작부터 결과 확인까지를 한 시퀀스로 기록합니다.
- 슛 위치는 슛을 놓는 순간 선수 발의 가운데를 기준으로 합니다.
- 림을 통과하면 성공, 통과하지 않으면 실패입니다.
- 슛 종류가 애매하면 억지로 정하지 않고 `확인 필요`로 기록합니다.
- 한 동작을 두 슛으로 중복 기록하지 않습니다.
- 공을 던졌지만 슛 의도가 아닌 패스는 슛으로 기록하지 않습니다.

## 11. 정확도 계산

### 슛 발견률

`프로그램이 올바르게 찾은 실제 슛 수 ÷ 실제 슛 수 × 100`

목표는 개인 연습 영상에서 80% 이상입니다.

### 잘못 추가한 슛

실제로는 슛이 아닌데 프로그램이 슛으로 만든 기록 수를 별도로 셉니다. 발견률이 높아도 잘못 추가한 슛이 많으면 좋은 결과로 보지 않습니다.

### 성공·실패 정확도

`성공·실패를 맞힌 슛 수 ÷ 프로그램이 올바르게 찾은 슛 수 × 100`

목표는 85% 이상입니다.

### 위치 정확도

- 예상한 14개 구역과 프로그램 구역이 같은지 기록합니다.
- 정확한 좌표 오차도 측정할 수 있으면 함께 기록합니다.
- 코트 선이 충분히 보이지 않는 YouTube 샘플 B는 공식 위치 정확도에 사용하지 않습니다.

### 슛 종류 정확도

- 종류별 맞은 수와 틀린 수를 기록합니다.
- `기타`와 `확인 필요` 비율도 함께 기록합니다.
- 스텝백·턴어라운드·훅슛은 Phase 8 결과를 보고 필수 여부를 판단합니다.

## 13. 전체 시험 시나리오

- 정상 MP4 등록
- MP4가 아닌 파일, 손상 파일, 10분·5GB 초과 거절
- 촬영·분석 동의와 OpenAI 안내 누락 차단
- 자동 코트 보정과 수동 보정
- 개인 선수 A 자동 생성
- 분석 시작, 진행, 화면 이동, 취소와 다시 분석
- OpenAI 정상, 키 없음, 연결 실패와 잘못된 응답
- 확인 필요 슛 검토
- 슛 추가·수정·삭제와 통계 재계산
- 2D 히트맵 14개 구역과 3D O/X 선택
- 30fps와 60fps 원본 시퀀스 재생
- 프로그램 재실행 후 기록 유지
- 삭제 취소와 원본·결과 동시 삭제
- 3대3 최대 6명 등록과 슈터 수동 수정

### 판정
