## 오늘 확정한 리포트 조건

- 표시되는 모든 슛의 유효한 위치와 성공/실패 결과가 확정돼야 개별·월간 요약을 생성하고 보낼 수 있다. UI 비활성화와 서버 차단을 함께 적용했다.
- 선택 집합 중 하나라도 미확정·진행 중·빈 분석이면 발송하지 않는다. 확인 저장 후 다시 조회하면 완료 상태를 반영한다.
- 여러 영상은 성공과 시도 수를 합산해 성공률·14구역 히트맵·연습 우선 구역을 계산한다. PDF 한 개와 메일 한 통으로 발송하며 영상별 성공률을 평균 내지 않는다. 추가 AI 호출은 없다.
- 인증된 본인 이메일과 저장된 프로필 수신동의만 사용한다. 신청·전송 직전 소유권·삭제·기록 변경·동의 철회·완료 상태를 검사한다. 요청ID 중복 방지, 동일 선택 대기/불확실 전송 차단,1분 재발송 제한을 적용했다.
- 새 `report_email_batches` 테이블에 발송 상태를 보관한다. 전송 시작을 먼저 저장해 중단 후 자동 재발송하지 않는다. 프로필 동의 철회 시 대기/준비 중 통합 요청도 취소한다.
