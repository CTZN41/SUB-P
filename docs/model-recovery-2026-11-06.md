# 2026-11-06 YOLO 모델 복구 기록

## 목적과 현재 범위

삭제된 로컬 농구 탐지 가중치를 이전 학습 자료와 명령으로 다시 만든다. Git에 보존된 서비스 기능·최근 후보 판정·접지·위치 보정 코드는 유지한다. 사람·농구공·림 객체 탐지 모델 복구와 OpenAI의 슛 종류·득점·위치 판정은 서로 다른 단계다. 모델 복구 자체는 OpenAI 호출·이메일 발송·사용자 기록 변경 없이 진행했고, 이후 사용자가 별도로 승인한 두 새 영상의 전체 AI 시험은 아래에 구분해 기록한다.

당시 순서에 따른 재학습·내부/별도 영상 검증·OpenVINO 변환과 서비스 배치를 완료했다. 원본 가중치 파일과 동일한 바이트가 복구됐다고 주장하지 않는다. 새 두 영상의 전체 Terra 분석과 연습 리포트·PDF도 완료했다.

## 화면 검증 범위

연결된 Browser Use와 Windows Computer Use는 모두 transport closed로 접근하지 못했다. 대신 기존 설치 Chrome을 별도 임시 프로필·headless로 실행해 실제 저장 응답을 현재 프런트에 연결했다. 이 시험 브라우저에서만 인증 설정 응답을 대체하고 모든 쓰기 요청을 차단했다. 운영 서버의 로그인 보호나 환경설정은 변경하지 않았다. 기존 로그인된 Chrome 세션에서의 직접 검증과 구분한다.

## 복구 보관본

바탕화면 `사이드 프로젝트/ShotLog-모델복구보관본-2026-11-06.zip`에 가중치·OpenVINO 두 모델·원본 학습 영상4개·마지막243장 이미지/라벨·v1~v4 체크포인트·조건·검증 자료·두 PDF·복구 안내를 보존했다. 약1.16GB이며 `.env`와 인증정보는 포함하지 않는다. ZIP의 모든 항목CRC와 압축된 실제 서비스 가중치의SHA-256 일치를 확인했다. ZIP옆의 `.zip.sha256`은 보관본 자체의 검사용이다.

해당 보관본은 모델·학습 자료를 함께 포함한다. 이후 모델 실행 파일은 Git에도 포함했으며, 학습 자료까지 담은 보관본은 소스만 있는 기존 공유용 보관본과 용도가 다르다. ZIP으로 복구하려면 `restore/backend/models`를 서비스의 `backend/models`로 복사하고 실제 `.env`는 별도로 보존한다.
