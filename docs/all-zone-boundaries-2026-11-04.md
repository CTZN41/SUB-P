# 14개 구역 경계 충돌 처리와 실제 시험 — 2026-11-04

## 결론

현재 14개 구역에서 맞닿는 경계 29쌍을 판정식에 맞춰 검사한다. 같은 거리 영역의 내부 구분 10쌍에는 엄격한 접지·좌표 근거가 있을 때만 이름을 좌표에 맞춘다. 골밑/페인트존/미드레인지/3점 사이의 실제 거리 경계 19쌍에는 이 예외를 적용하지 않는다. 기본 허용 폭은 15cm이며 30cm도 비교했다. XY와 신뢰도를 올리거나 마커를 이동하지 않는다.

더미 데이터의 저장·재조회·집계 시험은 통과했다. 그러나 실제 영상의 3번·18번 새 위치 판정은 자유투선과 신발 접촉이 불명확해 둘 다 보류였다. 기존 첫 응답의 구역 이름 충돌을 정리하는 기능과 실제 영상에서 정확한 접지점을 찾아내는 능력은 별개다. 이 시험을 전체 위치 정확도 향상률로 표현하지 않는다.

## 적용한 동작

- `court_zones.py`의 기존 판정식과 2D·3D 모양을 유지한다. 판정식의 선·원을 교차점에서 나누고 양쪽 판정이 실제로 다른 선분/호만 추린다. 49개 경계 조각이 29쌍을 구성하며 별도 운영 패키지는 추가하지 않았다.
- 내부 경계 예외: 페인트존 왼쪽↔중앙↔오른쪽, 미드레인지 베이스라인↔윙 및 윙↔정면, 3점 코너↔윙 및 윙↔정면. 골밑은 내부 분할이 없으므로 모든 접경을 실제 거리 경계로 취급한다.
- 거리 ≤15cm, 좌표 신뢰도 ≥70%, 검증된 코트 변환, 안정된 접지 참고 시각, 서로 다른 실제 신발 프레임 2개 이상, 영상의 3점 안/밖 일치, 근사 접지 환산값과 XY의 허용 폭 내 일치를 모두 요구한다. 화면 가장자리로 잘린 신발은 접지 증거에서 제외한다.
- 허용 폭 안에 실제 거리 경계나 코트 바깥이 함께 걸리면 예외를 막는다. 교차점에서도 적용된다. AI가 좌표·실제 거리 경계·구도 자체가 불명확하다고 명시하면 내부 구분 예외로 해결하지 않는다.
- AI는 XY 신뢰도와 구역 이름 신뢰도를 나눠 반환한다. 두 XY 신뢰도가 충돌하면 낮은 값을 사용한다. 재검토 질문도 실제로 충돌한 두 구역과 물리적 경계 문제를 구분한다.
- `ai_review.zone_boundary`에 원래 AI 구역, 좌표로 계산한 구역, XY, 경계 종류, 거리, 근거와 적용/거절 이유를 남긴다. 원래 모델 응답도 보존한다.
- 저장 시 소수점 4자리 반올림을 제거했다. 경계 위 점을 반올림하면 저장 구역과 저장 좌표의 구역이 달라지는 문제가 더미 시험에서 발견됐다. 초기 시험은 15cm 조건 14건, 30cm 조건 12건이었으며, 수정 후 모든 저장 좌표가 원래 XY 및 구역 판정과 일치했다. 표시용 반올림은 화면에서 수행한다. 기존 기록을 소급 수정하지 않는다.
