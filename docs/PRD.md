> 2026-11-03 추가 요구: 이메일 로그인·회원가입과 Google·카카오·네이버 간편 로그인 연결을 추가했습니다. 초기 회원가입 제외 범위는 확장됐습니다. Google 설정과 로컬 로그인 보호를 켜고 백엔드를 재시작했으며, Chrome에서 로그인된 홈과 새로고침 후 유지를 확인했습니다. 이메일 가입·네이버·카카오·두 계정 접근 분리는 아직 미검증입니다. 상세: [로그인 설정 안내](auth-setup.md).

## 2. 문서 목적

이 문서는 ShotMap AI의 첫 버전을 실제로 만들기 위한 제작 주문서입니다.

누가 이 서비스를 사용하고, 어떤 화면에서 무엇을 할 수 있어야 하며, 어디까지 동작하면 첫 버전이 완성된 것인지 정리합니다. 기술적인 구현 방법보다 사용자의 행동과 화면에 나타나는 결과를 중심으로 설명합니다.

## 3. 서비스 소개

ShotMap AI는 반코트 농구 영상을 분석하여 다음 결과를 보여주는 PC용 프로그램입니다.

- 슛을 던진 위치
- 슛의 성공 또는 실패
- 슛을 던진 선수
- 캐치 앤 슛, 풀업, 레이업 등의 슛 종류
- 성공과 실패를 한눈에 보는 3D 슈팅 맵
- 구역별 시도 수와 성공률을 보는 2D 히트맵

분석이 틀리거나 확실하지 않을 때는 사용자가 직접 기록을 고칠 수 있습니다.

## 4. 해결하려는 문제

농구 연습이나 경기를 촬영해도 영상을 처음부터 끝까지 다시 보면서 슛을 직접 세고 기록하기는 어렵습니다.

사용자는 다음 질문에 쉽게 답하기 어렵습니다.

- 나는 어느 위치에서 슛을 가장 많이 던졌는가?
- 어느 위치에서 슛 성공률이 높은가?
- 어떤 방식의 슛을 많이 사용했는가?
- 성공하거나 실패한 장면을 바로 다시 볼 수 있는가?
- 여러 명이 함께 있을 때 누구의 슛인지 구분할 수 있는가?

ShotMap AI는 긴 영상을 슛 기록으로 바꾸어 사용자가 자신의 슈팅 경향을 빠르게 이해하도록 돕습니다.

## 5. 주요 사용자

### 5.1 첫 번째 사용자

반코트에서 혼자 슈팅 연습을 하고, 고정된 카메라로 자신의 모습을 촬영하는 사람입니다.

### 5.2 확장 사용자

1대1, 2대2, 3대3 등 여러 명이 함께하는 반코트 영상을 분석하려는 사람입니다.

첫 버전에서 개인 연습 분석은 필수로 완성합니다. 3대3은 선수 등록, 화면에서 선수 지정, 선수별 기록과 결과 확인까지 기능을 완성합니다. 다만 발표 전 정확도 검증과 완료 판정은 개인 연습 영상으로 진행합니다. 3대3 자동 구분 정확도는 개발 결과를 별도로 기록합니다.

## 6. 첫 버전의 핵심 목표

첫 버전에서는 다음 경험을 완성하는 것이 가장 중요합니다.

> 사용자가 반코트 농구 영상을 등록하면, 프로그램이 슛을 분석하고, 사용자가 결과를 확인·수정한 뒤 3D 슈팅 맵과 2D 히트맵으로 다시 볼 수 있다.

실시간 분석보다 결과의 확인과 수정이 안정적으로 동작하는 것을 우선합니다.

## 7. 전체 사용 흐름

1. 사용자가 프로그램을 실행합니다.
2. 새 영상 등록 화면에서 MP4 파일을 선택합니다.
3. 1대1·2대2·3대3이면 첫 선수 이름을 선택적으로 입력합니다. 개인 연습은 `선수 A`로 시작합니다.
4. 다른 사람이 영상에 나오는지 선택하고, 필요한 경우 동의 안내를 확인합니다.
5. 프로그램이 영상 길이와 기본 촬영 조건을 확인합니다.
6. 사용자가 코트의 기준 위치가 맞는지 확인합니다.
7. 분석을 시작합니다.
8. 사용자는 진행 상태를 확인하거나 과거 기록 화면으로 이동합니다.
9. 분석이 끝나면 전체 슛 수와 성공률을 확인합니다.
10. 3D 슈팅 맵과 2D 히트맵을 전환하여 봅니다.
11. 슛 하나를 선택하여 원본 영상의 해당 장면을 재생합니다.
12. 잘못된 기록을 추가, 수정하거나 삭제합니다.
13. 수정 결과가 슈팅 맵과 히트맵에 반영됩니다.
14. 나중에 프로그램을 다시 실행해도 저장된 결과를 다시 볼 수 있습니다.
15. 필요하면 원본 영상과 분석 기록을 삭제합니다.

## 8. 기능 요구사항

### 8.1 영상 등록

#### 사용자가 할 수 있는 일

- PC에서 MP4 파일 한 개를 선택합니다.
- 분석 이름을 입력합니다.
- 개인 연습, 1대1, 2대2, 3대3 중 촬영 형태를 선택합니다.
- 촬영 날짜를 선택적으로 입력합니다.
- 1대1·2대2·3대3에서 첫 선수 이름을 선택적으로 입력합니다.
- 다른 사람이 영상에 포함되어 있는지 선택합니다.
- 다른 사람이 포함된 경우 촬영 및 분석 동의 안내를 확인합니다.
- 등록한 영상의 분석을 시작합니다.

#### 기본 조건

- 지원 형식은 MP4입니다.
- 최대 영상 길이는 40분입니다. (2026-11-04 사용자 요청으로 확대)
- 최대 파일 용량은 5GB입니다.
- 한 번에 영상 한 개를 등록합니다.
- 회원가입과 로그인은 필요하지 않습니다.

#### 화면에 보여줄 내용

- 선택한 파일 이름
- 분석 이름과 촬영 형태
- 선택적으로 입력한 촬영 날짜
- 영상 길이
- 가능하면 해상도와 초당 프레임 수
- 다인원 촬영에서만 첫 선수 이름 입력칸
- 다른 사람 포함 여부와 동의 안내
- 촬영 권장 조건
- 분석 시작 버튼

#### 잘못된 파일을 선택한 경우

- MP4가 아니면 지원하지 않는 형식이라고 알려줍니다.
- 40분을 넘으면 최대 길이를 알려주고 분석을 시작하지 않습니다.
- 파일을 읽을 수 없으면 다른 파일을 선택하도록 안내합니다.
- 촬영 조건이 좋지 않아도 파일을 바로 거절하지는 않고, 분석 정확도가 낮을 수 있다고 안내합니다.
- 분석 시작 화면에서 OpenAI 사용을 안내합니다. 새 영상 등록의 별도 OpenAI 확인 체크박스는 2026-11-04 사용자 요청으로 제거했습니다.

### 8.2 촬영 조건 안내

분석 전 다음 내용을 쉽게 확인할 수 있도록 보여줍니다.

- 반코트 전체가 화면 안에 들어와야 합니다.
- 골대와 림이 계속 보여야 합니다.
- 카메라는 고정해야 합니다.
- 촬영 중 화면을 돌리거나 확대하지 않는 것이 좋습니다.
- 선수의 발과 전신이 가능한 한 보여야 합니다.
- 최소 1080p를 권장합니다.
- 가능하면 60fps를 권장합니다.
- 카메라는 사이드라인 바깥쪽에서 하프코트 중앙과 골대를 함께 볼 수 있도록 비스듬히 설치할 수 있습니다.
- 가능하면 삼각대를 사용해 사람 눈높이보다 조금 높게 설치합니다.

### 8.3 코트 위치 맞추기

영상 속 코트와 분석용 코트의 위치를 맞추는 과정입니다.

#### 사용자가 할 수 있는 일

- 페인트존 또는 반코트 네 모서리가 보이는 장면을 고릅니다.
- 네 바닥 기준점과 골대 중심을 화면에서 직접 움직여 맞춥니다.
- 코트 위치가 맞으면 확인하고 다음 단계로 이동합니다.

#### 화면에 보여줄 내용

- 영상의 대표 장면
- 사용자가 직접 맞출 안내용 기준점
- 위치 조정 방법
- 기준 선택과 확인 버튼

바닥에서 확인할 수 있는 기준점을 최소 4개 사용하고 골대 위치를 별도로 확인합니다. 구체적인 위치와 조작 방법은 상세 동작 설명서에서 정합니다.

### 8.4 영상 분석

#### 분석할 항목

- 슛이 발생한 영상 시간
- 슛을 던진 코트 위치
- 성공 또는 실패
- 슛을 던진 선수
- 슛 종류
- 분석 결과의 확실한 정도

#### 슛 종류

한 번의 슛에는 대표 종류 하나를 저장합니다.

- 캐치 앤 슛
- 제자리 슛
- 드리블 풀업
- 사이드 스텝
- 레이업
- 덩크
- 페이더웨이
- 스텝백
- 턴어라운드
- 훅슛
- 기타
- 확인 필요

레이업은 골대로 달려가 공을 림 옆에서 위로 올려 놓는 슛이고, 덩크는 공을 쥔 채 림 높이에서 아래로 밀어 넣는 슛입니다. 두 종류는 따로 저장하고 통계에도 따로 표시합니다.

스텝백, 턴어라운드, 훅슛의 자동 분류는 정확도가 충분할 때 포함합니다. 정확도가 부족하면 `기타` 또는 `확인 필요`로 표시하며, 이 세 종류의 자동 분류는 첫 버전의 필수 완료 조건이 아닙니다.

#### 분석 중 화면

- 영상 이름
- `대기 중`, `분석 중`, `완료`, `실패`, `취소됨` 상태
- 진행 정도
- 현재 처리 중이라는 안내
- 예상 소요 시간은 실제 측정 결과를 얻은 뒤 표시 여부 결정

현재 PC에서 예상되는 처리 시간은 1분 영상 약 2~5분, 10분 영상 약 15~40분입니다. 이는 예상치이며 실제 개발 후 다시 측정합니다.

분석 중에는 취소 버튼을 제공합니다. 취소하면 원본 영상은 유지하고 완성되지 않은 중간 분석 결과는 제거합니다. 같은 영상으로 다시 분석할 수 있습니다.

#### 확실하지 않은 결과

- AI가 확실하게 판단하지 못한 슛도 없애지 않습니다.
- 해당 기록에 `확인 필요` 표시를 붙입니다.
- 사용자가 영상 장면을 보고 직접 확정하거나 수정합니다.

### 8.5 분석 결과 요약

분석이 완료되면 다음 내용을 먼저 보여줍니다.

- 영상 이름
- 선수 이름
- 전체 슛 시도 수
- 성공 수
- 실패 수
- 전체 성공률
- 확인이 필요한 기록 수
- 분석 완료 시간

여러 명이 포함되면 전체 선수 또는 특정 선수를 선택할 수 있습니다. 선택한 선수에 맞춰 요약, 3D 슈팅 맵, 히트맵과 기록 목록을 다시 계산합니다.

선수는 분석 전에 이름과 등번호를 입력하고 영상 화면에서 해당 인물을 눌러 지정합니다. 이름과 등번호를 모르면 등록 순서대로 `선수 A`, `선수 B`, `선수 C`와 같이 표시합니다.

### 8.6 3D 슈팅 맵

#### 기본 모습

- 나무 바닥 느낌의 반코트 3D 화면을 보여줍니다.
- 기본 카메라는 코트 전체와 슛 위치가 잘 보이는 대각선 시점입니다.
- 기록이 잘 보이도록 코트 장식은 단순하게 만듭니다.

#### 슛 표시

- 성공한 슛은 초록색 `O`로 표시합니다.
- 실패한 슛은 빨간색 `X`로 표시합니다.
- 색상뿐 아니라 모양도 다르게 하여 쉽게 구분하도록 합니다.

#### 사용자가 할 수 있는 일

- 마우스로 코트를 회전합니다.
- 확대하거나 축소합니다.
- 전체 선수 또는 특정 선수, 성공·실패, 슛 종류를 선택해 표시 범위를 좁힙니다.
- `O` 또는 `X`를 눌러 해당 슛의 상세 정보를 봅니다.
- 선택한 슛의 원본 영상 장면을 재생합니다.

3D 코트의 색상, 재질, 카메라 각도와 조작 방식은 초기 디자인 과정에서 정하되, 읽기 쉬운 것을 우선합니다.

### 8.7 2D 슈팅 히트맵

#### 기본 모습

- 반코트를 위에서 내려다본 형태로 보여줍니다.
- 코트를 여러 슈팅 구역으로 나눕니다.
- 각 구역의 성과를 색상과 숫자로 함께 표시합니다.

#### 구역별 표시 정보

- 성공 횟수 / 시도 횟수
- 해당 구역 성공률
- 전체 슛 중 해당 구역에서 던진 비율
- 해당 구역의 개인 연습용 목표 성공률

선수, 성공·실패 또는 슛 종류를 선택하면 선택 조건에 맞는 기록으로 히트맵과 수치를 다시 계산합니다.

#### 색상 기준

- 골밑 80%, 페인트존 60%, 미드레인지 45%, 3점 35%를 개인 연습용 목표로 사용합니다. 리그 평균이라는 뜻은 아닙니다.
- 성공·실패가 정해진 슛이 1개라도 있으면 해당 구역의 성공률이 목표 이상일 때 초록, 목표 미만일 때 빨강으로 표시합니다.
- 시도는 있으나 성공·실패가 모두 판단 불가인 구역은 중립색으로 표시합니다.
- 시도가 0개인 구역: `데이터 없음`

시도가 1~2개뿐이어도 결과를 그대로 표시합니다. 히트맵은 골밑, 페인트존, 미드레인지, 코너 3점, 윙 3점과 정면 3점을 포함하는 14개 구역으로 나눕니다. 상세 구역은 동작 설명서에서 정합니다.

### 8.8 슛 장면 다시 보기

#### 사용자가 할 수 있는 일

- 3D 슈팅 맵, 히트맵의 구역 또는 기록 목록에서 슛을 선택합니다.
- 선택한 슛의 원본 영상 장면을 봅니다.
- 장면을 일시 정지하거나 다시 재생합니다.
- 상세 정보에서 분석 결과를 수정합니다.

#### 재생 조건

- 슛 순간만 보여주지 않고 직전과 직후를 함께 보여줍니다.
- 원본이 60fps이면 재생 장면도 원본 60fps를 유지합니다.
- 원본 프레임 수가 낮으면 인위적으로 60fps로 만들지 않습니다.
- AI가 슛 준비가 시작된 순간부터 성공·실패 결과가 확인되는 순간까지 하나의 전체 슛 시퀀스로 선택합니다.
- AI가 시작과 끝을 확실히 찾지 못하면 슛 후보 시점 5초 전부터 3초 후까지 보여줍니다.
- 선택 구간이 지나치게 길어지면 최대 20초까지 우선 보여주고, 사용자는 원본 영상의 해당 위치를 이어서 볼 수 있습니다.

### 8.9 분석 기록 수정

#### 사용자가 할 수 있는 일

- 빠진 슛을 추가합니다.
- 잘못 인식된 슛을 삭제합니다.
- 슛 위치를 수정합니다.
- 성공과 실패를 바꿉니다.
- 선수를 바꿉니다.
- 슛 종류를 바꿉니다.
- `확인 필요` 기록을 확정합니다.

#### 수정 후 결과

- 수정한 기록을 저장합니다.
- 전체 슛 수와 성공률을 다시 계산합니다.
- 3D 슈팅 맵과 2D 히트맵을 바로 갱신합니다.
- 프로그램을 다시 실행해도 수정 결과가 유지됩니다.

### 8.10 과거 분석 기록

#### 목록에서 보여줄 내용

- 영상 이름
- 선수 이름
- 등록 날짜
- 영상 길이
- 분석 상태
- 전체 슛 수
- 성공률

#### 사용자가 할 수 있는 일

- 과거 결과를 다시 엽니다.
- 분석이 완료된 기록을 3D 슈팅 맵과 히트맵으로 봅니다.
- 원본 영상을 다시 봅니다.
- 기록과 원본 영상을 삭제합니다.

첫 버전에서는 최근 등록 순서로 목록을 보여줍니다. 검색과 별도 필터는 만들지 않습니다.

### 8.11 삭제

- 삭제 전 확인 메시지를 보여줍니다.
- 사용자가 확인하면 원본 영상과 해당 분석 기록을 삭제합니다.
- 삭제가 끝나면 목록에서 사라집니다.
- 삭제한 자료의 복구 기능은 첫 버전에 포함하지 않습니다.

원본 영상과 해당 분석 기록은 항상 함께 삭제합니다.

### 8.12 분석 실패 처리

- 실패 상태와 사용자가 이해할 수 있는 이유를 보여줍니다.
- 원본 영상은 자동으로 삭제하지 않습니다.
- 사용자가 조건을 확인한 뒤 다시 분석할 수 있도록 합니다.
- 실패한 중간 결과를 어디까지 보관할지는 상세 설계에서 정합니다.

## 10. 화면 디자인 원칙

첫 버전은 PC 화면만 지원합니다.

- 전체 분위기: 어두운 스포츠 분석 대시보드
- 배경: 짙은 남색 또는 차콜색
- 코트: 따뜻한 나무색
- 성공: 초록색과 `O`
- 실패: 빨간색과 `X`
- 강조: 밝은 파란색
- 글자: 흰색에 가까운 밝은 색
- 기본 글꼴: Pretendard 우선
- 카드와 버튼: 조금 둥근 모서리와 단순한 형태
- 색상만으로 상태를 구분하지 않고 글자와 모양을 함께 사용

기본 배치는 다음과 같습니다.

- 왼쪽: 새 분석과 분석 기록 메뉴
- 위쪽: 영상과 전체 결과 요약
- 가운데: 3D 슈팅 맵 또는 2D 히트맵
- 오른쪽 또는 아래쪽: 선택한 슛의 영상과 상세 정보

구체적인 색상 값, 글자 크기, 여백과 3D 코트 모습은 화면 설계 단계에서 정합니다.

## 12. 개인정보와 비밀정보

- 다른 사람이 영상에 포함되어 있으면 동의 안내를 보여줍니다.
- 사용자가 직접 삭제하기 전까지 원본 영상을 현재 PC에 보관합니다.
- 다른 사용자에게 결과를 공개하거나 공유하지 않습니다.
- OpenAI API 키는 환경설정 파일에서 관리합니다.
- API 키를 코드, 문서, Git 기록 또는 화면에 표시하지 않습니다.
- OpenAI에는 전체 영상이 아니라 슛 후보에서 필요한 장면만 전달합니다.
- 등록 화면에서 외부 AI가 후보 장면을 처리할 수 있다는 안내를 보여주고 확인을 받습니다.
- OpenAI의 실제 보관 정책은 개발 시점의 공식 정책을 확인해 안내문에 반영합니다.

## 13. AI 사용 원칙

영상 전체를 AI 대화 모델에 한 번에 맡기는 방식에만 의존하지 않습니다.

- 영상 분석 프로그램은 선수, 공, 골대와 슛 후보를 찾습니다.
- OpenAI는 후보 장면의 슛 종류, 성공·실패와 슛 위치를 14개 코트 구역으로 판단합니다.
- 고정 카메라 장면은 대표 화면으로 카메라 방향을 한 번만 판단하고, 같은 장면의 모든 슛 위치에 동일한 방향을 적용합니다.
- 카메라 방향과 슛 위치는 Terra만 판단합니다. 위치 신뢰도가 75% 미만이면 다른 모델로 덮어쓰지 않고 사용자가 확인할 기록으로 남깁니다.
- 사용자는 확실하지 않거나 잘못된 결과를 최종 확인합니다.

비용과 처리 시간을 줄이면서도 결과를 확인할 수 있는 구조를 우선합니다. 정확한 모델과 호출 방법은 개발 시작 시점의 지원 기능과 가격을 확인한 뒤 상세 설계에서 정합니다.

## 14. 첫 버전 완료 기준

다음 항목이 모두 동작하고 직접 확인되면 첫 버전이 완성된 것으로 봅니다.

1. PC에서 MP4 파일을 선택할 수 있습니다.
2. 40분이 넘는 영상과 잘못된 형식을 구분합니다.
3. 개인정보 안내와 필요한 동의 확인이 동작합니다.
4. 사용자가 코트 위치를 확인하고 틀린 위치를 조정할 수 있습니다.
5. 개인 연습 영상에서 슛 후보를 찾습니다.
6. 슛의 시간, 위치와 성공·실패를 저장합니다.
7. 주요 슛 종류를 표시합니다.
8. 애매한 기록을 `확인 필요`로 구분합니다.
9. 사용자가 슛 기록을 추가, 수정, 삭제할 수 있습니다.
10. 수정된 결과가 전체 통계에 반영됩니다.
11. 3D 코트에 성공 `O`와 실패 `X`가 표시됩니다.
12. 2D 히트맵에 구역별 시도 수와 성공률이 표시됩니다.
13. 슛 기록을 선택하면 해당 영상 장면을 볼 수 있습니다.
14. 프로그램을 다시 실행해도 영상 정보와 분석 결과가 남아 있습니다.
15. 원본 영상과 분석 기록을 삭제할 수 있습니다.
16. 1분과 10분 테스트 영상의 처리 시간과 분석 결과를 기록합니다.
17. 사용자가 이해할 수 있는 분석 실패 안내와 다시 시도 방법이 있습니다.
18. 분석을 취소하면 원본은 남고 미완성 결과는 제거됩니다.
19. 3대3에서 최대 6명의 이름·등번호를 등록하거나 `선수 A~F`로 지정할 수 있습니다.
20. 영상 화면에서 선수를 눌러 등록한 선수와 연결할 수 있습니다.
21. 전체 선수와 특정 선수 결과를 선택해 볼 수 있습니다.

지원 촬영 조건을 만족하는 개인 연습 영상에서 슛 발견률 80% 이상, 발견한 슛의 성공·실패 판단 정확도 85% 이상을 1차 개발 목표로 삼습니다. 이는 테스트 목표이며 모든 영상에 대한 정확도 보장은 아닙니다.

## 2026-11-02 결과 분류·번호 표시 확정

결과 요약은 전체 후보·성공·실패·위치 확인 필요·결과 확인 필요로 구분한다. 결과 미정 우선 → 위치 미정 → 성공/실패 순서로 하나의 분류에만 넣어 합계가 일치하게 한다. 위치·결과 모두 미정인 기록은 결과 확인 필요에만 집계한다. 위치와 결과가 모두 확정돼 저장되면 성공/실패로 이동한다. 목록 필터도 같은 네 분류를 사용한다. 3D 바닥 마커는 성공 초록·실패 빨강 바탕에 흰 슛 번호를 표시하며 목록과 같은 번호로 원본 장면에 연결한다. 필터·구역 선택으로 번호를 바꾸지 않는다.

## 2026-11-03 구도별 기준점과 3점선 보조 설정

- 같은 영상에 대표 시각별 코트 구도를 여러 개 저장한다. 같은 시각을 수정하면 그 구도만 갱신하고 다른 구도는 보존한다. 기존 단일 구도도 사용할 수 있다.
- 각 구도에 페인트존 네 모서리와 림을 수동 지정한다. 3점선은 선택 사항이며 화면에 보이는 구간만 선을 따라 순서대로 지정한다. 45도~45도 부분 지정도 허용하고 보이지 않는 끝은 연결하지 않는다.
- 바닥 기준점 주변의 실제 영상 대응까지 검증한 구도에서만 숫자 좌표를 재사용한다. 배경 대응만 맞거나 구도 기준이 없는 경우 위치를 자동 확정하지 않는다.
- 3점선은 발 위치와 AI의 선 안/밖 판정을 검증하는 보조 근거다. 선 접촉·경계 또는 불일치 시 위치 확인 필요로 보존하며 새로운 좌표를 임의 생성하지 않는다.
- 이 기능 추가는 과거 분석·사용자 수정 기록을 자동 재분석하거나 덮어쓰지 않는다.
