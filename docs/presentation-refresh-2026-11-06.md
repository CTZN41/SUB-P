## 현재 표시값과 근거

새 모델로 같은 원본247장에 실제 추론을 수행했습니다. 현재 서비스와 같은640/960 크기 보강과 고정 배경 공 탐지 제외 규칙을 사용했습니다. 표시는24fps로 재구성한 발표용 설명이며 과거 분석의 전체 처리 과정을 실시간 녹화한 영상은 아닙니다. 탐지하지 못한 객체의 상자는 임의로 추가하지 않았습니다.

실제 탐지의2.125초와2.542초 공 위치를 현재 릴리스 후보 규칙에 넣은 예시를 보여줍니다. 별도로 실제 전체 분석에서 후보2.00초→릴리스2.50초, 후보8.80초→릴리스8.60초로 보정한 기록을 표시합니다. YOLO만으로 성공/실패를 확정한다고 설명하지 않습니다.

코트는 가상 반코트50×47ft, 페인트존16×19ft입니다. 네 바닥점은(17,0),(33,0),(33,19),(17,19)에 대응하고 림 중심은 추적용 별도 기준입니다. 실제 저장된2.067초 장면의 선수 상자 하단 참고점(1387.76,622.57)px을 원근 변환하면(35.2556,16.0362)ft입니다. 정밀 신발 접지점 측정값은 아닙니다. 최종 AI 저장 좌표(35.3,16.0)ft는 영상 근거를 함께 검토한 별도 결과입니다.

현재 두 슛은2.50초 성공·오른쪽45도 미드레인지,8.60초 실패·오른쪽 베이스라인 미드레인지이며 둘 다 드리블 풀업입니다. 실제 저장 판정을 설명한 것이고 새 유료API 호출은 없습니다. 전체1639프레임 디코딩과 주요 자막·상자·좌표·림 장면을 확인했습니다.
