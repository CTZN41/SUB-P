# 농구 슈팅 분석 서비스 MVP

> 2026-11-03 추가 요구: 이메일 로그인·회원가입과 Google·카카오·네이버 간편 로그인 연결을 추가했습니다. 초기 회원가입 제외 범위는 확장됐습니다. Google 설정과 로컬 로그인 보호를 켜고 백엔드를 재시작했으며, Chrome에서 로그인된 홈과 새로고침 후 유지를 확인했습니다. 이메일 가입·네이버·카카오·두 계정 접근 분리는 아직 미검증입니다. 상세: [로그인 설정 안내](auth-setup.md).

## 1. 문서 목적

> 2026-11-04 추가 범위: 이메일 가입의 닉네임 입력과 간편로그인 뒤 첫 닉네임 설정, 내 프로필 조회·미등록 비밀번호 등록을 추가합니다. 실제 저장과 같은 이메일 재로그인은 사용자 직접 검증이 남아 있으며 그 외 프로필 기능은 추가하지 않습니다.

이 문서는 농구 영상을 분석하여 선수의 슈팅 위치와 성공률을 보여주는 첫 번째 버전의 범위를 정리한 문서입니다.

개발을 모르는 사람도 어떤 서비스를 만들고, 어디까지 완성하면 되는지 쉽게 이해할 수 있도록 작성했습니다.

현재 서비스 이름은 **ShotLog**입니다(2026-11-03 확정). 초기 문서의 ShotMap AI와 이후 Baseline AI는 이전 이름이며, 저장소명 SUB-P는 유지합니다.

## 2. 서비스 한 줄 소개

반코트 농구 영상을 올리면 AI가 슛의 위치, 성공 여부, 슛 종류를 분석하고 **3D 슈팅 맵**과 **2D 히트맵**으로 보여주는 PC용 서비스입니다.

## 3. 해결하려는 불편

개인 농구 영상만 보고서는 다음 내용을 정확히 기억하거나 직접 세기 어렵습니다.

- 어느 위치에서 슛을 많이 던졌는지
- 어느 위치의 성공률이 높은지
- 어떤 슛을 성공하거나 실패했는지
- 캐치 앤 슛, 풀업, 레이업 등 어떤 방식으로 슛했는지
- 여러 명이 함께 경기했을 때 어떤 선수의 기록인지

ShotMap AI는 영상을 기록으로 바꾸어, 사용자가 자신의 슛 경향을 한눈에 확인하도록 돕습니다.

## 4. 주요 사용자

첫 버전의 가장 중요한 사용자는 **반코트에서 혼자 슈팅 연습을 촬영하는 사람**입니다.

향후에는 1대1, 2대2, 3대3 영상도 분석할 수 있도록 확장합니다. 다만 여러 명을 자동으로 구분하는 기능은 난도가 높기 때문에, 첫 버전에서는 사용자가 선수를 직접 선택하거나 분석 결과를 고칠 수 있는 보조 방식을 사용할 수 있습니다.

## 5. 첫 버전의 목표

첫 버전은 다음 흐름이 처음부터 끝까지 동작하면 완성된 것으로 봅니다.

1. 사용자가 최대 40분 길이의 MP4 농구 영상을 선택합니다. (2026-11-04 확대)
2. 영상에 다른 사람이 나오면 촬영 및 업로드 동의를 확인하는 안내에 체크합니다.
3. 코트가 잘 보이는 장면을 골라 네 바닥 기준점과 골대 중심을 직접 맞춥니다.
4. 프로그램이 슛 장면을 찾아 위치, 성공 여부, 슛 종류를 분석합니다.
5. 사용자는 분석 중인 상태와 완료 여부를 확인합니다.
6. 분석 결과를 3D 슈팅 맵과 2D 히트맵으로 확인합니다.
7. 잘못 분석된 기록은 사용자가 추가, 수정, 삭제할 수 있습니다.
8. 프로그램을 껐다 켜도 기존 분석 결과가 남아 있습니다.
9. 사용자는 원본 영상과 분석 기록을 직접 삭제할 수 있습니다.

## 6. 첫 버전에 포함할 기능

### 6.1 영상 등록

- 지원 파일: MP4
- 최대 영상 길이: 40분
- 선수 이름: 선택 입력
- 원본 영상: 분석 후에도 보존
- 삭제: 사용자가 원할 때 직접 삭제
- 개인정보 안내: 다른 사람의 얼굴이 포함된 경우 동의 확인 체크박스 제공

### 6.2 영상 분석

프로그램은 다음 항목을 분석합니다.

- 슛이 발생한 시간
- 슛을 던진 코트 위치
- 성공 또는 실패
- 슛을 던진 선수
- 슛 종류
- 분석 결과를 확실하게 판단했는지 여부

AI가 확실하게 판단하지 못한 기록은 숨기지 않고 **확인 필요**로 표시합니다. 사용자가 영상을 보고 결과를 바로잡을 수 있어야 합니다.

### 6.3 슛 종류

한 번의 슛에는 가장 알맞은 종류 하나를 표시합니다.

- 캐치 앤 슛: 공을 받은 뒤 바로 던진 슛
- 제자리 슛: 큰 이동이나 드리블 없이 던진 슛
- 드리블 풀업: 드리블하다가 멈춰서 던진 슛
- 사이드 스텝: 옆으로 발을 옮겨 공간을 만든 뒤 던진 슛
- 레이업
- 덩크
- 페이더웨이
- 스텝백
- 턴어라운드
- 훅슛
- 기타
- 확인 필요

스텝백, 턴어라운드, 훅슛은 구현할 수 있으면 첫 버전에 포함합니다. 하지만 정확도가 부족하면 `기타` 또는 `확인 필요`로 표시하며, 이 세 종류의 자동 구분은 첫 버전의 필수 완료 조건으로 삼지 않습니다.

### 6.4 기록 직접 수정

자동 분석은 항상 완벽할 수 없으므로 사용자가 다음 내용을 고칠 수 있어야 합니다.

- 빠진 슛 추가
- 잘못 잡힌 슛 삭제
- 슛 위치 수정
- 성공·실패 수정
- 선수 수정
- 슛 종류 수정

수정한 결과는 3D 슈팅 맵과 히트맵에 바로 반영합니다.

### 6.5 분석 기록 보관

- 첫 버전에서는 회원가입과 로그인을 만들지 않습니다.
- 한 명이 현재 PC에서 사용하는 방식으로 시작합니다.
- 분석 결과와 수정 내용은 프로그램을 다시 실행해도 유지합니다.
- 영상 목록에서 과거 분석 결과를 다시 열 수 있습니다.

## 7. 결과 화면

### 7.1 3D 슈팅 맵

3D 화면에서는 반코트 위에 각 슛을 개별 표시합니다.

- 성공한 슛: 초록색 `O`
- 실패한 슛: 빨간색 `X`
- 기본 시점: 코트 전체와 슛 위치를 보기 쉬운 대각선 시점
- 화면 조작: 마우스로 회전하고 확대·축소
- 슛 선택: `O` 또는 `X`를 누르면 해당 슛 장면과 상세 정보 표시

3D 코트의 형태, 재질, 카메라 각도와 표시 방식은 초기 개발 과정에서 직접 정합니다. 실제 경기장의 나무 바닥 느낌을 살리되, 기록이 코트보다 먼저 눈에 들어오도록 단순하고 선명하게 만듭니다.

원본이 60fps 영상이면 해당 슛 장면도 60fps를 유지합니다. 원본 영상의 프레임 수가 낮으면 억지로 60fps로 만들지 않습니다.

### 7.2 2D 슈팅 히트맵

히트맵은 코트를 위에서 내려다본 모습으로 보여줍니다. 코트를 여러 슈팅 구역으로 나누고, 각 구역에 다음 정보를 표시합니다.

- 성공 횟수 / 시도 횟수
- 해당 구역의 성공률
- 전체 슛 중 해당 구역에서 던진 비율
- 이번 영상 전체 성공률과 비교한 결과

전체 성공률보다 높은 구역은 초록색 계열, 낮은 구역은 빨간색 계열, 비슷한 구역은 밝은 중간색으로 표현합니다. 색상만으로 판단하지 않아도 되도록 숫자를 함께 표시합니다.

슛이 1~2개뿐이어도 결과를 표시합니다. 슛이 0개인 구역만 `데이터 없음`으로 표시합니다.

### 7.3 슛 장면 다시 보기

3D 슈팅 맵이나 기록 목록에서 슛 하나를 선택하면 원본 영상의 해당 장면으로 이동합니다.

- 슛 직전과 직후를 함께 재생
- 선택한 선수, 위치, 성공 여부, 슛 종류 표시
- 잘못된 결과를 바로 수정할 수 있는 버튼 제공

## 8. PC용 초기 디자인 방향

첫 버전은 **PC 화면만 지원**합니다. 휴대폰과 태블릿 화면 최적화는 이번 범위에 포함하지 않습니다.

초기 디자인은 다음 방향으로 진행합니다.

- 전체 분위기: 어두운 스포츠 분석 대시보드
- 배경색: 짙은 남색 또는 차콜색
- 코트색: 따뜻한 나무색
- 성공 표시: 초록색
- 실패 표시: 빨간색
- 강조색: 밝은 파란색
- 글자색: 흰색에 가까운 밝은 색
- 글꼴: 한글과 숫자가 선명한 `Pretendard` 우선 사용
- 카드와 버튼: 모서리를 조금 둥글게 하고, 지나친 장식 없이 단순하게 구성

기본 화면은 다음과 같이 배치합니다.

- 왼쪽: 영상 등록, 분석 기록 등 주요 메뉴
- 위쪽: 영상 이름, 선수 이름, 전체 슛 수, 성공률 요약
- 가운데: 3D 슈팅 맵 또는 2D 히트맵
- 오른쪽 또는 아래쪽: 선택한 슛의 영상과 상세 정보
- 보기 전환: `3D 슈팅 맵`과 `히트맵` 탭 제공

색상, 글꼴, 세부 여백, 3D 코트의 초기 디자인은 개발 과정에서 직접 정하되, 결과를 읽기 쉽고 발표 화면에서도 잘 보이는 것을 가장 중요한 기준으로 삼습니다.

## 9. 촬영 조건

분석 정확도를 높이기 위해 첫 버전에서는 다음 촬영 조건을 권장합니다.

- 반코트 전체가 화면 안에 들어오도록 촬영
- 골대와 림이 영상에서 계속 보이도록 촬영
- 카메라는 한 곳에 고정
- 촬영 중 화면을 좌우로 돌리거나 확대하지 않기
- 선수의 발과 전신이 가능한 한 보이도록 촬영
- 최소 1080p 권장
- 가능하면 60fps 권장
- 코트 옆에서 하프코트를 비스듬히 바라보는 구도 사용 가능

촬영 조건을 만족하지 못한 영상은 분석할 수 있더라도 정확도가 낮아질 수 있다는 안내를 보여줍니다.

### 9.1 개발용 샘플 영상

초기 개발과 기능 확인에는 다음 두 YouTube 영상을 사용합니다. 두 영상은 역할이 다르므로 같은 기준으로 평가하지 않습니다.

#### 샘플 A: 슛 감지와 위치 분석용

- 영상: [Improve Your Shooting By Yourself | Full Solo Basketball Shooting Workout](https://www.youtube.com/watch?v=ss10AxV3OzI)
- 우선 사용할 구간: 영상 초반 약 `0:10~1:33`
- 사용하는 목적: 선수와 공 찾기, 슛 후보 찾기, 성공·실패 판단, 코트 위 슛 위치 추정의 초기 시험
- 장점: 한 명의 선수가 보이고, 초반 구간에는 골대와 선수 전신, 일부 코트 선이 함께 보임
- 주의점: 영상 뒤쪽에는 가까운 화면과 편집 전환이 있으며 골대가 보이지 않는 장면도 있으므로, 전체 영상을 위치 분석의 정답 영상으로 사용하지 않음

#### 샘플 B: 긴 영상 흐름과 슛 종류 분석용

- 영상: [혼자서 농구 훈련 (무편집) | How To Practice Basketball By Yourself](https://www.youtube.com/watch?v=giPL6ixkkhk)
- 우선 사용할 구간: `0:00~10:00` 이내 구간. 앱의 최대 10분 제한을 넘지 않도록 잘라서 준비
- 사용하는 목적: 긴 영상에서 슛 후보를 나누는 기능, 제자리 슛과 드리블 풀업 등 슛 종류를 구분하는 기능, 분석 취소와 진행 상태 시험
- 장점: 한 명이 비교적 긴 시간 동안 연습하며 화면 전환이 적음
- 주의점: 카메라가 낮고 코트 선이 충분히 보이지 않아 정확한 좌표와 히트맵의 최종 검증에는 사용하지 않음

두 영상은 개발 초기에 기능이 동작하는지 확인하는 참고 자료입니다. 최종 정확도와 MVP 완료 여부는 촬영 권장 조건을 만족하고 사람이 정답을 미리 작성한 별도의 직접 촬영 영상으로 확인합니다.

YouTube 영상은 프로젝트에 원본 파일로 포함하거나 발표 자료에 재사용하기 전에 제작자의 허락 또는 사용 가능한 라이선스를 확인합니다.

## 10. AI가 맡는 일과 프로그램이 맡는 일

영상 전체를 AI 대화 모델에 그대로 보내는 방식만 사용하지 않습니다. 비용과 처리 시간, 정확도를 관리하기 위해 역할을 나눕니다.

- 영상 분석 프로그램: 선수, 공, 골대와 슛 후보 장면을 찾고, 사용자가 지정한 코트 기준점으로 슛 위치를 계산함
- OpenAI: 슛 종류를 판단하고 애매한 장면의 판단을 보조함
- 사용자: 잘못되거나 확실하지 않은 결과를 최종 확인하고 수정함

OpenAI API 키는 나중에 서버의 환경설정 파일에서 관리하며 코드나 문서에 적지 않습니다.

## 11. 예상 처리 시간

현재 PC에는 별도의 NVIDIA 그래픽카드가 없으므로 영상 분석은 실시간보다 느릴 수 있습니다. 초기 예상은 다음과 같으며, 실제 개발 후 반드시 다시 측정합니다.

- 1분 영상: 약 2~5분
- 10분 영상: 약 15~40분

화면에는 진행 상태를 표시하여 프로그램이 멈춘 것으로 보이지 않게 합니다. 더 빠른 처리가 필요해지면 추후 클라우드 GPU 사용을 검토합니다.

## 12. 발표 때의 실시간 분석

발표에서 영상을 올린 즉시 실시간에 가깝게 분석할지는 **아직 확정하지 않습니다**.

개발하면서 현재 PC에서 실제 처리 속도와 정확도를 측정한 뒤 다음 중 하나를 선택합니다.

1. 짧은 영상을 현장에서 직접 분석
2. 일부 장면만 현장에서 분석하고 긴 영상은 미리 분석한 결과 사용
3. 미리 분석한 결과를 중심으로 발표

실시간 분석은 첫 버전의 필수 완료 조건이 아닙니다. 느린 환경에서도 업로드, 분석 진행 상태, 완료된 결과 확인 흐름이 안정적으로 동작하는 것을 먼저 완성합니다.

## 13. 첫 버전 완료 기준

다음 항목을 모두 직접 확인하면 첫 버전이 완성된 것으로 봅니다.

- PC에서 MP4 영상을 등록할 수 있다.
- 최대 40분 제한과 개인정보 안내가 동작한다.
- 개인 연습 영상에서 슛 후보를 찾을 수 있다.
- 슛 위치와 성공·실패 결과가 저장된다.
- 주요 슛 종류를 표시하고 애매한 결과는 `확인 필요`로 구분한다.
- 사용자가 잘못된 기록을 추가, 수정, 삭제할 수 있다.
- 3D 코트에 성공 `O`와 실패 `X`가 표시된다.
- 2D 히트맵에 구역별 시도 수와 성공률이 표시된다.
- 슛 표시를 누르면 해당 영상 장면을 볼 수 있다.
- 프로그램을 다시 켜도 분석 기록이 남아 있다.
- 원본 영상과 분석 기록을 사용자가 삭제할 수 있다.
- 1분과 10분 테스트 영상의 처리 시간과 정확도를 기록한다.

- 공의 정확한 3D 궤적 재현
