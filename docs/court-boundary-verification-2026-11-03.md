# 14구역 경계와 숫자 마커 검증

## 무엇을 바꿨는가

화면의 임의 곡선·사선 구역과 실제 좌표 판정이 다르던 부분을 고쳤다. 기존 백엔드 판정에서 도형을 생성하고 같은 좌표를 2D SVG와 3D 삼각형에 사용한다. 수동 위치 지정 화면의 3점선도 같은 원을 사용한다.

숫자는 카메라가 높으면 바닥에 눕고, 낮으면 세워지도록 한다. 마커 크기는 기본 1.9ft·선택 2.2ft로 줄였다. 골대가 정면인 낮은 첫 구도와 축소 한도도 반영했다.

## 실제 확인한 내용

| 확인 | 방법 | 결과 |
|---|---|---|
| 코트의 빈틈·중복 | 생성된 14구역의 전체 면적·교집합 검사 | 통과 |
| 판정과 도형 | 코트 전체 37,600점에서 백엔드 판정과 도형 내부 대조 | 통과 |
| 경계선 판정 | 직선·원 경계 위와 양옆에서 Python과 프론트 판정 대조 | 통과 |
| 3D의 실제 도형 | 실제 생성된 삼각형에 위에서 광선을 쏴 2,000곳 이상 판정과 대조 | 통과 |
| 마커 각도 | 높은 각도부터 낮은 각도까지 1도 간격으로 연속 변화 검사 | 통과 |

Chrome 시험은 기존 구간 검증 기록 `c0351cf5-fc10-4967-ab14-fc802099b817`을 읽어서 진행했다. 슛 수정·저장·삭제·AI 재실행은 하지 않았다. 빠르게 구역을 연속 선택한 첫 시험에서 React 반영 전 상태를 읽은 1건은 별도로 다시 선택해 일치함을 확인했다.

## 경계에 대한 주의

- 2D·3D의 원은 4096개 선분으로 표시한다. 실제 원과의 최대 차이는 0.00001ft 미만이다.
- SVG와 GPU 삼각형의 정확한 경계선은 양쪽 도형이 함께 갖는 선이다. 마우스 선택은 원래 좌표 판정의 우선순위를 사용한다.
- GPU는 Float32 좌표를 사용하므로 삼각형 검사에서는 경계에서 0.00005ft 이내인 점의 소속을 도형 겹침 순서로 확정하지 않는다. 이 점들의 정확한 분류는 별도의 Python·프론트 판정 비교로 검사한다.
- 이번 시험은 화면과 분류 기준의 일치 시험이다. 영상 속 선수 발 위치나 AI의 실제 슛 위치 추정 정확도를 새로 측정한 것은 아니다.
- 최종 마커 크기, 정면 첫 시점 및 모든 회전 각도에서의 최대 축소 모양은 사용자의 추가 확인 대상이다. 같은 위치의 슛이 완전히 분리된다고 보장하지 않는다.

## 다시 시험하는 방법

백엔드 폴더에서:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-geometry.txt
.\.venv\Scripts\python.exe scripts/generate_court_geometry.py --check
.\.venv\Scripts\python.exe -m pytest tests/test_shared_court_geometry.py tests/test_court_zones.py tests/test_shot_statistics.py -q
```

프론트 폴더에서:

```powershell
node --test tests/court*.test.mjs tests/shotPresentation.test.mjs
npm run build
```

기준이 바뀌면 `--check`를 뺀 생성 명령으로 공유 도형을 갱신한 뒤 위 시험을 다시 실행한다. 기하 도형 생성 도구는 개발용이며 서비스 실행 시 자동으로 설치하거나 실행하지 않는다.

### 가독성 확인용 임시 마커

사용자 요청으로 개발용 URL의 `markerPreview=1` 모드에 오른쪽 베이스라인 테스트 마커 12개(101~112번)를 배치했다. 두 개는 좌표가 같고 여러 개는 가까이 겹친다. Chrome에서 표시 안내·마커 수와 실제 화면을 확인했다. 기록이나 통계에는 저장하지 않으며 일반 URL에서는 보이지 않는다. 현재 사용자가 이 화면에서 가독성을 비교할 수 있다.


### 2026-11-03 임시 마커 확인 종료

사용자가 가독성 확인을 마쳤다. 요청에 따라 101~112번 임시 마커와 개발용 표시 모드·안내를 코드에서 제거했다. 실제 슛 기록과 최종 마커 크기·각도 전환·카메라 설정은 유지한다. 다음은 일반 결과 화면으로 계속 사용한다. 위의 markerPreview 설명은 당시 시험 기록이며 현재 기능은 아니다.
